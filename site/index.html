Chrome extension · free · open source

Rewrite your prompt before you send it.

AskWise puts a small Improve button next to the message box on ChatGPT, Claude, Gemini, Perplexity, DeepSeek and Copilot. Type the rough version of what you want. Press it. You get back a prompt that spells out the task, the shape of the answer, and what would make it good — ready for you to read, edit and send.

The bracketed parts are blanks left for you on purpose. AskWise never invents a number, a company or a traceback you didn't give it — it marks the gap and asks you to fill it. The score is a fixed rubric, not an opinion: task clarity, specificity, context, output format, constraints, audience, and success criteria.

How it works

Three seconds, start to finish.

  1. Type it badly.

    Write the prompt the way it comes out of your head — typos, missing words, all of it. Once you're eight characters in, the Improve pill appears beside the composer. Alt + I does the same thing without the mouse.

  2. AskWise reads the ask.

    A set of rules running on your machine sorts the prompt — is this a debugging problem, a cover letter, a comparison, a data question? — and picks a matching template from more than seventy of them. There's no model call, so there's no wait.

  3. You get a prompt and a reason.

    The rewrite comes back with a before-and-after score and a diff showing exactly what was added. Change anything you don't like, then send it. AskWise never sends anything for you.

What's in it

Specific tools for specific asks.

A prompt about a failing SQL query needs different treatment from a eulogy. AskWise keeps separate templates rather than wrapping everything in the same preamble.

A template per kind of ask
Among them: writing, research, coding help, debugging, data analysis, résumés and interviews, app builds, agent tasks, and short factual questions. Underneath those sit the narrow cases — getting a résumé past an applicant tracking system, negotiating salary, speeding up a slow query, writing cold outreach that doesn't read like a template.
A score you can argue with
The 0–100 number is a deterministic rubric, not a model's judgement. If your prompt loses points on context, AskWise names what's missing — "say who it's for or what you're working on" — rather than telling you to try harder.
Held to a test suite
More than 290 hand-labelled prompts run through classification, rewriting and scoring on every change, including deliberately awkward ones. A rewrite that stops behaving fails the build.
Six sites
ChatGPT, Claude, Gemini, Perplexity, DeepSeek and Microsoft Copilot. Each one gets its own adapter, because they all build their composer differently.
An optional local model
Instant rewrites are templates and rules — they work offline and download nothing. If you want the Advanced rewrite or the Refine box, AskWise runs Qwen2.5 3B inside your browser over WebGPU. Its weights (about 1.9 GB) download once and stay in the browser cache. Your prompt still never leaves the machine.

Privacy

Where your text goes

Nowhere. There is no AskWise server to send it to.

The part that reads your prompt, picks a template, rewrites it and scores it is ordinary JavaScript running inside the extension on your computer. The examples further up this page were produced by running that same code straight from the repository — no network involved, and the output is identical every time.

Advanced rewrites use a language model, and that model also runs on your machine. The one thing AskWise ever downloads is the model's weight files, once, from Hugging Face — and only if you switch Advanced on. Your prompt is not part of that request.

No account, no sign-in, no analytics, no ads. AskWise doesn't read your browsing history and doesn't read your conversation — only the text sitting in the composer, and only when you ask it to. Before anything reaches the local model, it tries to strip obvious secrets like API tokens, email addresses and card numbers.

Install

Two minutes, from source.

The Chrome Web Store listing isn't live yet. Until it is, you build AskWise yourself. You'll need Node and Chrome 113 or newer. 

$ git clone https://github.com/anish-ap2938/AskWise
$ cd AskWise
$ npm install
$ npm run build
  1. Open chrome://extensions and switch on Developer mode.
  2. Choose Load unpacked and select the dist folder.
  3. Open ChatGPT, type a few words, and look for the Improve pill under the box.

Questions

Fair things to ask

Does it answer the prompt for me?

No. AskWise only rewrites the prompt. The answer still comes from whichever AI you're using, and you're the one who presses send.

Does it replace my own words?

It keeps your wording as the core of the rewrite and builds structure around it. The result lands in the composer as editable text — delete half of it if you like.

Do I have to download the 1.9 GB model?

No. Instant rewrites are rules and templates: they work offline and download nothing. The model is only for Advanced rewrites and Refine, and it stays off until you turn it on.

Firefox? Safari?

Not yet. AskWise is a Chrome MV3 extension and leans on Chrome's extension APIs and WebGPU. Other browsers would need real work, not a flag.

What's the catch on "free"?

There isn't one. There's no paid tier behind a trial, no rewrite quota, no card on file. Since nothing runs on a server, nothing costs anything to run.

Free, and staying that way

Writing a clear prompt shouldn't cost money.

AskWise is MIT licensed and open from top to bottom. Read the rules that classify your prompt, read the templates, disagree with the scoring, send a patch. It was built so that the people who get the least out of AI tools — because nobody taught them the trick of asking properly — get the same leg up as everyone else.
