Privacy Policy for AskWise

Effective date: July 16, 2026
Last updated: July 17, 2026
Product: AskWise (Chrome extension)
Developer: AskWise open-source project (github.com/anish-ap2938/AskWise)

This Privacy Policy explains how the AskWise Chrome extension (“AskWise”, “we”, “us”) handles information when you install and use the extension. This page is the official privacy policy for AskWise.

1. Overview

AskWise improves text that you type into AI chat composers (for example ChatGPT, Claude, Gemini, Perplexity, DeepSeek, and Microsoft Copilot). AskWise does not operate an AskWise backend server, does not create user accounts, and does not use analytics or advertising trackers.

2. Information the extension accesses

When you use AskWise, the extension may access:

  • Website content in the active chat composer — the prompt text currently in the input box on a supported AI website, only when you open or use AskWise.
  • Local settings and saved templates — preferences you choose in the extension options page, stored on your device.
  • Optional API keys you enter — Anthropic or OpenAI keys, if you choose to enable bring-your-own-key (BYOK).
  • Optional local files you attach — files you select for context (.txt, .md, .pdf), read with browser file APIs and parsed on your device.

AskWise does not read your full browsing history, does not read chat message history outside the active composer when you use Improve, and does not collect health, financial, or location data for any AskWise service.

3. How information is used

  • To classify and rewrite your prompt into a clearer, structured prompt.
  • To show before/after scoring, diffs, and variants inside the extension UI.
  • To remember your settings, templates, and optional provider configuration.
  • To run optional Advanced rewrites using on-device, local, or user-configured cloud models.

We do not sell user data. We do not use user data for advertising. We do not use user data to determine creditworthiness.

4. What leaves your device

  • Default / Simple / Structured improve: processed entirely on your device. No prompt text is sent to an AskWise server (there is none).
  • On-device model download: AskWise may download model weights and related WebAssembly runtime assets from Hugging Face / MLC content delivery networks into your browser cache. Your prompts are not sent to those CDNs. Inference runs locally via WebGPU in an extension offscreen document.
  • Optional local model server: if you enable Ollama or LM Studio, Advanced requests may be sent to an address you configure (typically localhost on your machine).
  • Optional cloud BYOK: if you paste your own Anthropic or OpenAI API key, Advanced rewrite requests are sent directly to that provider using your key. Secrets such as tokens and emails are redacted locally before the request when possible.

5. Storage and retention

Settings, templates, optional API keys, and on-device model download progress are stored in chrome.storage.local on your device. Cached model weights may be stored in the browser’s Cache Storage. This data remains until you clear it in the extension options, clear site/extension data in Chrome, or uninstall AskWise. AskWise does not retain copies of your prompts or keys on any AskWise-operated server.

6. Third parties

AskWise may communicate with the following third parties only for the features described above:

  • Supported AI chat websites (to inject the improve UI into the composer).
  • Hugging Face / MLC CDNs (model weight download only).
  • Optional: Anthropic API or OpenAI API when you provide a key.
  • Optional: a local model server you configure.

Those third parties’ privacy practices are governed by their own policies. AskWise does not control how a provider you choose may handle data you send with your own key.

7. Children’s privacy

AskWise is not directed to children under 13, and we do not knowingly collect personal information from children.

8. Changes to this policy

We may update this Privacy Policy from time to time. The “Last updated” date at the top of this page will change when we do. Continued use of AskWise after an update means you accept the revised policy.

9. Contact

For privacy questions about AskWise, open an issue at https://github.com/anish-ap2938/AskWise/issues or contact the publisher email listed on the Chrome Web Store listing.
