Privacy Policy for AskWise

Effective date: July 16, 2026
Last updated: July 17, 2026
Product: AskWise (Chrome extension)
Developer: AskWise open-source project (github.com/anish-ap2938/AskWise)

This Privacy Policy explains how the AskWise Chrome extension (“AskWise”, “we”, “us”) handles information when you install and use the extension. This page is the official privacy policy for AskWise.

1. Overview

AskWise improves text that you type into AI chat composers (for example ChatGPT, Claude, Gemini, Perplexity, DeepSeek, and Microsoft Copilot). AskWise does not operate an AskWise backend server, does not create user accounts, and does not use analytics or advertising trackers.

2. Chrome Web Store Limited Use Compliance

AskWise’s use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. AskWise uses user data only to provide or improve its disclosed prompt-improvement functionality and does not use or transfer user data for advertising, creditworthiness, or unrelated purposes.

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

3. Information the extension accesses

When you use AskWise, the extension may access:

  • Website content in the active chat composer — the prompt text currently in the input box on a supported AI website, only when you open or use AskWise.
  • User-selected file attachments — files you choose for context (.txt, .md, .pdf), read with browser file APIs and parsed on your device.
  • Local settings and saved templates — preferences you choose in the extension options page, stored on your device.

AskWise does not intentionally request or separately collect health, financial, or precise location information. However, prompt text or files selected by a user may contain such information. AskWise processes that content only to provide the features described in this policy.

AskWise does not read your full browsing history and does not read chat history outside the active composer when you use Improve.

4. How information is used

  • To classify and rewrite your prompt into a clearer, structured prompt.
  • To show before/after scoring, diffs, and variants inside the extension UI.
  • To remember your settings, templates, and on-device model selection.
  • To run Advanced rewrites and Refine requests with the built-in on-device model.

We do not sell user data. We do not use user data for advertising. We do not use user data to determine creditworthiness or for lending purposes.

5. What leaves your device

  • Default / Simple / Structured improve: processed entirely on your device. No prompt text is sent to an AskWise server (there is none).
  • Advanced / Refine: prompt inference runs locally in the extension using the built-in WebLLM model and WebGPU. Prompt content is not sent to an external AI provider.
  • On-device model data (once per model): AskWise may download model weights, tokenizer files, model configuration files, and other non-executable model data from Hugging Face or MLC content delivery networks into the browser’s Cache Storage. The JavaScript and WebAssembly runtime used for inference is included in the installed extension package. AskWise does not download or execute remotely hosted code. Your prompts are not sent to those CDNs; inference runs locally via WebGPU.

6. Redaction and review

Before on-device inference, AskWise attempts to redact common sensitive-data patterns, such as API tokens, email addresses, and payment-card numbers. Automated redaction may not identify every sensitive value, so users should review generated prompts before using them.

7. Websites where AskWise operates

AskWise runs a content script on supported AI chat websites to display its interface and access the active composer. AskWise does not independently transmit prompt text to those websites. A website receives the resulting prompt only when the user submits it through that website normally.

8. Third-party services

  • Hugging Face or MLC infrastructure receives model-download requests for non-executable model data, but does not receive prompt content.

AskWise does not send prompt content to an AskWise server or an external AI provider. Supported AI chat websites receive the resulting prompt only when the user submits it there normally.

9. Storage and retention

Settings, templates, and on-device model download progress are stored in chrome.storage.local on your device. Cached model weights may be stored in the browser’s Cache Storage. This data remains until you clear it in the extension options, clear site/extension data in Chrome, or uninstall AskWise. AskWise does not retain copies of your prompts on any AskWise-operated server.

10. Permissions

  • storage — settings, templates, and model download progress
  • offscreen — run the on-device WebGPU model in a hidden document
  • Host permissions for supported chat sites — inject the composer widget and read the active composer
  • Hugging Face / related CDNs — download non-executable on-device model data once into browser cache

11. Children’s privacy

AskWise is not directed to children under 13, and we do not knowingly collect personal information from children.

12. Changes to this policy

We may update this Privacy Policy from time to time. The “Last updated” date at the top of this page will change when we do. Continued use of AskWise after an update means you accept the revised policy.

13. Contact

For privacy questions about AskWise, open an issue at github.com/anish-ap2938/AskWise/issues or contact the publisher email listed on the Chrome Web Store listing.
