AskWise Privacy Policy

Last updated: July 2026

Summary

AskWise processes your prompt text locally in your browser. We do not operate a backend server, do not sell data, and do not collect analytics or telemetry.

What we access

  • Only the text in the chat composer on supported AI chat sites when you use the extension.
  • Settings, saved templates, and optional API keys you enter — stored in chrome.storage.local on your device.
  • Optional local file attachments you choose — parsed on-device and never uploaded to an AskWise server.

What leaves your device

  • Nothing by default for Simple/Structured rewrites. Tier 1 improvements are fully offline.
  • On-device model weights (once): on install, AskWise may download a small instruct model (~1 GB) from Hugging Face / MLC CDNs into the browser’s Cache Storage. Your prompts are not sent to those CDNs; inference runs locally via WebGPU.
  • Optional local server: if you enable Ollama / LM Studio, Advanced requests go to localhost on your machine.
  • Optional cloud BYOK: only if you paste your own Anthropic or OpenAI API key. Secrets are redacted locally before any cloud call.

Permissions

  • storage — settings, templates, keys, model download progress
  • offscreen — run the on-device WebGPU model in a hidden document
  • Host permissions for supported chat sites — inject the composer widget only
  • Hugging Face / GitHub raw — download model weights once
  • localhost — optional Ollama / LM Studio
  • Anthropic / OpenAI APIs — only when you configure a key

Data retention

Templates, settings, cached model weights, and API keys persist locally until you delete them or uninstall the extension. We do not retain copies on any AskWise server.

Contact
